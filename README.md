# Ashadeep Computer Institute website

TanStack Start (React) site that runs on Cloudflare Workers.

- Deploy and go-live guide: **DEPLOY.md**
- Enquiry form: sends to a Google Sheet + Gmail through `docs/google-apps-script/Code.gs`
  (no database, no Supabase, no Resend)

## Run locally
```bash
npm install --legacy-peer-deps
npm run dev
```
Other commands: `npm run build`, `npm run lint`, `npm test`.
